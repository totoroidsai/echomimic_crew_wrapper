# echomimic_crew_wrapper
Script to generate text content, convert it to audio, and use it for echomimic video generation

Needs: Echomimic, TTS, Ollama, and crewai

Assuming Ollama/mistral is running on default http://localhost:11434 =>

1. Prerequiste install: git clone https://github.com/antgroup/echomimic_v2.git

2. git clone https://github.com/totoroidsai/echomimic_crew_wrapper.git

3. conda activate echomimic_crew_wrapper

4. cd echomimic_crew_wrapper

5. pip install -r requirements.txt

6.  python generate_podcast_stream.py
